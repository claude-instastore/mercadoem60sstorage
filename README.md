# mercadoem60sstorage

Artes já publicadas do **Mercado em 60s** (@mercado.em60s), servidas para a API do Instagram.

Este repositório é **público de propósito**: a Meta baixa as imagens por URL, sem autenticação.
Ele contém apenas arte que já foi ao ar — nada de código, credencial ou dado privado.

O projeto que gera este conteúdo fica num repositório privado separado.

Estrutura: `AAAA-MM-DD-chave/slide-01.jpg`, `story.jpg`, etc.

Desde 11/2026 também guarda as capas dos vídeos da **ÓRBITA** (@orbita.curtas), em `orbita/AAAA-MM-DD-id/capa.jpg`.
